# Overview
Developmental regulatory programs unfold continuously across space and time, yet spatial epigenomic measurements remain inherently discontinuous, captured as fragmented sections across platforms, stages, resolutions and fields of view. Existing approaches can integrate observed sections, but a framework to infer and test whether the continuity between fragmented regulatory landscapes is biologically supported remains lacking. Here we introduce SPHERE (Spatial Panoramic Holistic Epigenomic REpresentation), a framework for panoramic atlas completion (PAC) that reconstructs evidence-supported regulatory continuity from incomplete spatial epigenomic observations. By integrating topology–regulatory graph learning, attention-based fusion and cross-section manifold consistency, SPHERE establishes a reusable regulatory coordinate system that transforms regulatory continuity from an assumption into a measurable property. Across eleven mouse embryonic sections generated by four spatial epigenomic technologies spanning six developmental stages, SPHERE reconstructs a coherent regulatory atlas while preserving anatomical organization, developmental ordering and telencephalic regulatory transitions. A frozen SPHERE reference places held-out developmental stages and sections from unseen platforms without retraining, while temporal-gap and spatial-overlap experiments define empirical boundaries of supported completion. With single-cell epigenomic references, SPHERE resolves cell-type and regulatory programs in atlas space, and anchor-guided correspondence transfer enables three-dimensional regulatory landscape reconstruction. A memory-efficient strategy further scales atlas assembly to 7.09 million spatial bins. Together, SPHERE transforms fragmented spatial epigenomic observations into an extensible and auditable framework for studying developmental regulatory programs as continuous landscapes rather than disconnected measurements.

# System Requirements
## Hardware requirements
`SPHERE` package requires only a standard computer with enough RAM to support the in-memory operations.

## Software requirements
### OS Requirements
This package is supported for *Linux*. The package has been tested on the following systems:
+ Linux: Ubuntu 22.04

### Python Dependencies
`SPHERE` mainly depends on the Python scientific stack.
```
numpy
scipy
torch
scikit-learn
pandas
scanpy
```
For specific setting, please see <a href="https://github.com/Philyzh8/SPHERE/blob/master/requirements.txt">requirements</a> or <a href="https://github.com/Philyzh8/SPHERE/blob/master/environment.yaml">environment</a>.

# Installation Guide:

### Install from PyPi

```
$ conda create -n SPHERE_env python=3.8.15
$ conda activate SPHERE_env
$ pip install -r requirements.txt
```

### Install from Conda

```
$ conda env create -f environment.yaml
```

# Usage
:page_facing_up: `SPHERE` is a unified framework that models each slice with spatial and regulatory graphs, fuses them via attention, and enforces cross-slice manifold consistency to mitigate platform-specific biases while preserving developmental progression, which can be used to:
+ <a href="https://github.com/Philyzh8/SPHERE/tree/master/Tutorial/Tutorial1%3A%20Platform-agnostic%20structural%20consistency">Tutorial1</a>. Platform-agnostic structural consistency.
+ <a href="https://github.com/Philyzh8/SPHERE/tree/master/Tutorial/Tutorial2%3A%20Developmental%20continuity%20across%20stages">Tutorial2</a>. Developmental continuity across stages.
+ <a href="https://github.com/Philyzh8/SPHERE/tree/master/Tutorial/Tutorial3%3A%20Omni-platform%20spatiotemporal%20panoramic%20completion">Tutorial3</a>. Omni-platform spatiotemporal panoramic completion.
+ <a href="https://github.com/Philyzh8/SPHERE/tree/master/Tutorial/Tutorial4%3A%20Multi-million-bin%20cross-resolution%20spatial%20maps/Cerebellum">Tutorial4</a>. Multi-million-bin cross-resolution spatial maps.
+ <a href="https://github.com/Philyzh8/SPHERE/tree/master/Tutorial/Tutorial5%3A%20Insert%20held-out%20fragments">Tutorial5</a>. Insert held-out fragments.
+ <a href="https://github.com/Philyzh8/SPHERE/tree/master/Tutorial/Tutorial6%3A%20Panoramic%20reconstruction">Tutorial6</a>. Realize regulatory correspondences in physical tissue space.
+ <a href="https://github.com/Philyzh8/SPHERE/tree/master/Tutorial/Tutorial7%3A%20Panoramic%20annotation">Tutorial7</a>. Interpret regulatory landscapes through single-cell epigenomic references.
